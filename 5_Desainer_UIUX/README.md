# 5. Desainer UI/UX

- `prototype/codefishing.html`: prototipe interaktif (buka di browser) yang menjadi acuan semua layar dan alur
- `panduan/DESAIN.md`: palet, font, prinsip
- Kode tema: `app/src/main/java/com/example/codefishing/ui/theme/` (`Color.kt`, `Type.kt`, `Theme.kt`)

Tugas: pasang font (taruh di `app/src/main/res/font`, ubah `Type.kt`), rapikan warna, serahkan desain layar ke tim Frontend. Logo resmi ada di `2_Aset_dan_Konten/logo`.
Prinsip evaluasi dosen: minimalis, banyak gambar, toolbar hamburger seragam, tanpa tombol Kembali, Pengenalan sekali di awal.
